# Literature boundary notes

This repo lives near several established areas. None should be silently renamed as a discovery here.

## Fast weights / test-time memory

Fast Weight Programmers and related linear-attention interpretations already establish that a neural system can carry matrix-valued state that changes during inference. Delta-rule fast weights can correct associations online rather than merely accumulate them.

Starting points:

- Schlag, Irie & Schmidhuber (2021), *Linear Transformers Are Secretly Fast Weight Programmers*, arXiv:2102.11174.
- Irie & Gershman (2025), *Fast weight programming and linear transformers: from machine learning to neurobiology*, arXiv:2508.08435.

Therefore "a matrix changes while the model runs" is not the WhatIsI claim.

## Test-time memorization

Titans (Behrouz, Zhong & Mirrokni, 2025; arXiv:2501.00663) adds a neural long-term memory that learns at test time. Modern test-time-training/memory systems make persistent adaptation an active architecture area.

Therefore "persistent learned memory beside attention" is also not enough.

## Self-models

Recent work reports that auxiliary self-modelling can reduce neural-network complexity and increase parameter efficiency. This motivates a future attacker: if an explicit self latent is useful, is its advantage simply regularization/compression?

- *Unexpected benefits of self-modelling in neural systems* (2026), PubMed PMID 42130428.

## Memory for self-actions

Memory for one's own actions is actively studied as distinct from passive event memory, and has been proposed to interact with a generative self-model.

- Mazor, Seghezzi & Manohar (2026), *Remembering what you did: Episodic memory for self-actions*, PMID 42140366.

Complementary-learning-systems work is also relevant to the slow/fast split: rapid episodic storage and slower statistical learning need not use the same update mechanism.

## Strict boundary

Evidence for any of the following must not be silently promoted into evidence for phenomenal consciousness:

- persistent memory;
- agency inference;
- self/other classification;
- metacognition;
- first-person language;
- an intervenable self-address.

WhatIsI currently studies only functional self-modelling/control variables.
